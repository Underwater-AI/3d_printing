## Project Overview

Underwater AI 3D Printing Service is a production-grade web application for ordering 3D prints powered by Bambu Lab P2S printers. The platform allows users to:

- Upload 3D model files (STL, 3MF, OBJ, STEP)
- Configure print settings (material, color, infill, supports)
- Get real-time price estimates
- Pay via Razorpay
- Track order status

The application is based at IISER Kolkata Campus, Mohanpur, Nadia, West Bengal, and is funded by MeitY, Government of India.
